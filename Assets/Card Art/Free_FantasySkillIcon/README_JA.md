# Free Fantasy Skill Icon

## 概要
Free Fantasy Skill Icon は Fantasy Skill Icon コレクションの無料プロモーション用サンプルパッケージです。**100 個のユニークなファンタジー RPG スキルアイコン**と、**100 個の簡略版 UI バリアント**を含み、合計 **200 個の PNG Sprite アセット**で構成されています。

現在のパッケージ内容は、実際に含まれているクラスフォルダ **assassin, cleric** を基準に整理されています。

## 内容
- SkillIcon/ - 詳細スキルアイコン。
- SkillIcon_Simplified/ - 小さな UI スロット向けの簡略版。
- SkillDescriptions/ - ランタイム連携とドキュメント用の JSON / Markdown メタデータ。
- Demo/ - Unity サンプルシーン内容。

## クラス内訳
| クラス | 詳細アイコン | 簡略版アイコン |
| --- | ---: | ---: |
| assassin | 50 | 50 |
| cleric | 50 | 50 |

## JSON データ
パッケージにはすぐ利用できる JSON ファイルが含まれています。

- SkillDescriptions/Free_FantasySkillIcon_Skills_Index.json - items 配列を持つラッパー形式。
- SkillDescriptions/Free_FantasySkillIcon_Skills_Array.json - id、name、category、icon、simplifiedIcon を使う配列形式。
- SkillDescriptions/Free_FantasySkillIcon_Skills_Detailed.json - スキル説明と制作メタデータを含む詳細データ。

アイコンパスは Assets/Free_FantasySkillIcon/ からの相対パスです。

## 技術仕様
- 形式：PNG
- 推奨 Texture Type：Sprite (2D and UI)
- 背景：透過アイコンファイル
- 詳細アイコン：100
- 簡略版アイコン：100
- PNG 合計：200
