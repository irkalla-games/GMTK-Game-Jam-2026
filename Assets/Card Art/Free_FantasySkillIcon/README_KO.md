# Free Fantasy Skill Icon

## 개요
Free Fantasy Skill Icon 패키지는 Fantasy Skill Icon 컬렉션의 무료 홍보용 샘플 패키지입니다. **고유 판타지 RPG 스킬 아이콘 100개**와 **심플 UI 버전 100개**를 포함하며, 총 **PNG Sprite 에셋 200개**로 구성되어 있습니다.

현재 패키지 내용은 실제 포함된 클래스 폴더인 **assassin, cleric** 기준으로 정리되어 있습니다.

## 구성
- SkillIcon/ - 디테일 스킬 아이콘.
- SkillIcon_Simplified/ - 작은 UI 슬롯에 쓰기 좋은 심플 버전.
- SkillDescriptions/ - 런타임 연동과 문서화를 위한 JSON / Markdown 메타데이터.
- Demo/ - Unity 샘플 씬 콘텐츠.

## 클래스 구성
| 클래스 | 디테일 아이콘 | 심플 아이콘 |
| --- | ---: | ---: |
| assassin | 50 | 50 |
| cleric | 50 | 50 |

## JSON 데이터
패키지에는 바로 사용할 수 있는 JSON 파일이 포함되어 있습니다.

- SkillDescriptions/Free_FantasySkillIcon_Skills_Index.json - items 배열을 가진 wrapper 형식.
- SkillDescriptions/Free_FantasySkillIcon_Skills_Array.json - id, name, category, icon, simplifiedIcon을 사용하는 배열 형식.
- SkillDescriptions/Free_FantasySkillIcon_Skills_Detailed.json - 스킬 설명과 제작 메타데이터를 포함한 상세 데이터.

아이콘 경로는 Assets/Free_FantasySkillIcon/ 기준 상대 경로입니다.

## 기술 사양
- 형식: PNG
- 권장 Texture Type: Sprite (2D and UI)
- 배경: 투명 아이콘 파일
- 디테일 아이콘: 100
- 심플 아이콘: 100
- 총 PNG 파일: 200
