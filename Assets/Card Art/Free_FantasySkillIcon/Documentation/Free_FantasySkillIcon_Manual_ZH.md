# Free Fantasy Skill Icon

## 概述
Free Fantasy Skill Icon 是 Fantasy Skill Icon 系列的免费宣传示例包。它包含 **100 个独立幻想 RPG 技能图标**，以及 **100 个简化 UI 版本**，总计 **200 个 PNG Sprite 资源**。

当前资源内容按照实际包含的职业文件夹整理：**assassin, cleric**。

## 内容
- SkillIcon/ - 详细技能图标。
- SkillIcon_Simplified/ - 适合紧凑 UI 槽位的简化版本。
- SkillDescriptions/ - 用于运行时集成和文档说明的 JSON 与 Markdown 元数据。
- Demo/ - Unity 示例场景内容。

## 职业数量
| 职业 | 详细图标 | 简化图标 |
| --- | ---: | ---: |
| assassin | 50 | 50 |
| cleric | 50 | 50 |

## JSON 数据
资源包包含可直接使用的 JSON 文件：

- SkillDescriptions/Free_FantasySkillIcon_Skills_Index.json - 包含 items 数组的包装对象。
- SkillDescriptions/Free_FantasySkillIcon_Skills_Array.json - 使用 id、name、category、icon、simplifiedIcon 的纯数组。
- SkillDescriptions/Free_FantasySkillIcon_Skills_Detailed.json - 包含技能说明和制作元数据的详细数据。

图标路径相对于 Assets/Free_FantasySkillIcon/。

## 技术规格
- 格式：PNG
- 建议 Texture Type：Sprite (2D and UI)
- 背景：透明图标文件
- 详细图标：100
- 简化图标：100
- PNG 总数：200
