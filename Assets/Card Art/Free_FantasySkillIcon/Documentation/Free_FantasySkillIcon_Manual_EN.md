# Free Fantasy Skill Icon

## Overview
Free Fantasy Skill Icon is a free promotional sample package from the Fantasy Skill Icon collection. It includes **100 unique fantasy RPG skill icons** and **100 simplified UI variants**, for a total of **200 PNG sprite assets**.

The current package content is organized by the actual included class folders: **assassin, cleric**.

## Contents
- SkillIcon/ - detailed skill icons.
- SkillIcon_Simplified/ - simplified variants for compact UI slots.
- SkillDescriptions/ - JSON and Markdown metadata for runtime integration and documentation.
- Demo/ - sample Unity scene content.

## Class Breakdown
| Class | Detailed Icons | Simplified Icons |
| --- | ---: | ---: |
| assassin | 50 | 50 |
| cleric | 50 | 50 |

## JSON Data
The package includes ready-to-use JSON files:

- SkillDescriptions/Free_FantasySkillIcon_Skills_Index.json - wrapper object with an items array.
- SkillDescriptions/Free_FantasySkillIcon_Skills_Array.json - plain array using id, name, category, icon, and simplifiedIcon.
- SkillDescriptions/Free_FantasySkillIcon_Skills_Detailed.json - detailed production metadata with skill descriptions and generation notes.

Icon paths are relative to Assets/Free_FantasySkillIcon/.

## Technical Specifications
- Format: PNG
- Intended Texture Type: Sprite (2D and UI)
- Background: transparent icon files
- Detailed icons: 100
- Simplified icons: 100
- Total PNG files: 200
